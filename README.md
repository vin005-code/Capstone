# AlgoPilot – AI-Powered Coding Platform

## About the Project

AlgoPilot is a coding and learning platform inspired by LeetCode. The main idea behind this project is to make learning programming and problem-solving easier for students.

Users can practice coding problems, submit their solutions, track their progress, and get help from an AI assistant whenever they get stuck. The platform also helps students understand what they have completed and what they should focus on learning next.

We wanted to build something that goes beyond just solving coding questions and actually helps students improve their programming skills step by step.

## Features

- **User Login:** Separate login access for students, teachers, and admins.
- **Coding Problems:** Students can explore and solve problems based on different topics and difficulty levels.
- **Code Submission:** Users can write code and submit their solutions for evaluation using test cases.
- **AI Assistant:** An integrated AI assistant helps students understand problems, clear doubts, and get guidance while coding.
- **Learning Plans:** Keeps track of what students have completed and helps them decide what to learn next.
- **Progress Tracking:** Students can view their submissions and monitor their learning progress.
- **Teacher Dashboard:** Allows teachers to manage learning activities and monitor students.
- **Admin Dashboard:** Helps manage users and other platform activities.

## Technologies Used

- Node.js – Backend
- Express.js – Backend framework
- PostgreSQL – Database
- Prisma – ORM
- Gemini API – AI integration
- JWT – Authentication

## What We Aim to Achieve

Through AlgoPilot, we aim to create a platform where students can learn, practice, and improve at their own pace.

Rather than simply showing the correct answer to a coding problem, we want to help students understand the logic behind it, identify their mistakes, and gradually become better problem solvers.
